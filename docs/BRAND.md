# هویت برند «دانه»

> برند «دانه» ساختگی است و برای این نمونه‌کار طراحی شده است.

## ایده اصلی

**قهوه تازه، با اطلاعات شفاف.** مشتری قبل از خرید باید بداند قهوه از کجا آمده، چقدر برشته شده و چه طعمی دارد. همه تصمیم‌های طراحی، از برچسب بسته تا کارت محصول در سایت، در خدمت همین ایده‌اند.

## نشانه‌ها

| عنصر | انتخاب |
| --- | --- |
| نام‌نوشته | «دانه» با وزیرمتن Black، به رنگ اسپرسو `#1F1B18` |
| رنگ اصلی سایت | گیلاس قهوه `#A8233A` برای دکمه‌ها و سبز برگ `#2F5D45` برای زمینه‌های آرام |
| بسته | کیسه کرافت خام با برچسب کرم؛ جنس بسته خودش بخشی از طراحی است |
| رنگ هر خاستگاه | یک نوار رنگی روی برچسب، که همان رنگ در سایت هم استفاده می‌شود |
| درجه برشت | پنج نقطه؛ هرچه پرتر، تیره‌تر. روی بسته، کارت محصول و راهنمای «کدام برشت برای شماست؟» یکسان است |

## برچسب بسته

از بالا به پایین: نام‌نوشته، «برشتکاری قهوه»، نوار خاستگاه (کشور و منطقه یا روش فرآوری)، سه طعم اصلی، پنج نقطه درجه برشت، وزن و نوع (دانه کامل).

## عکاسی

- **عکس اصلی محصول:** همه بسته‌ها با یک زاویه، یک نور و یک پس‌زمینه طوسی روشن. این یکدستی، صفحه فروشگاه را مرتب و حرفه‌ای نشان می‌دهد.
- **عکس دوم گالری:** داستان قهوه، یعنی دانه، میوه قهوه یا روش دم‌آوری، با نور گرم و طبیعی.
- **ممنوع:** عکس از سایت فروشگاه‌های دیگر، و عکسی که لوگوی برند دیگری در آن دیده می‌شود.

## ایده‌هایی که از بررسی برندهای قهوه تخصصی گرفته شد

برشتکاری‌های تخصصی در بسته‌بندی و سایتشان چند کار مشترک انجام می‌دهند. «دانه» بعضی را اجرا کرده و بقیه قدم‌های بعدی‌اند:

| ایده | وضعیت در «دانه» |
| --- | --- |
| طعم‌ها با خط درشت، به‌عنوان مهم‌ترین اطلاعات | اجرا شده: روی برچسب و کارت محصول |
| مقیاس درجه برشت روی بسته | اجرا شده: پنج نقطه |
| جنس بسته به‌عنوان بخشی از طراحی (کرافت، چاپ تک‌رنگ) | اجرا شده |
| اطلاعات خاستگاه: منطقه، روش فرآوری، ارتفاع | منطقه و فرآوری روی برچسب؛ ارتفاع در توضیح محصول |
| **تاریخ برشت و شماره بچ** روی هر بسته | قدم بعدی: با برچسب کوچک یا مهر روی هر بسته؛ در سایت هم وعده داده شده است |
| کد QR به راهنمای دم‌آوری همان قهوه | قدم بعدی |
| نام کشاورز یا ایستگاه فرآوری | قدم بعدی، وقتی اطلاعات واقعی تأمین‌کننده باشد |
| نسخه محدود فصلی با طراحی متفاوت | قدم بعدی |

یک درس دیگر: دو سبک جواب می‌دهد، «مینیمال روی کرافت» (سبک دانه) یا «تصویرسازی پررنگ و کامل». حالت وسط، مثل عکس استوک تکراری روی بسته، برند را بی‌هویت می‌کند.
