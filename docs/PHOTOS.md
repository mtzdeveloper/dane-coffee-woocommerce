# تصاویر فروشگاه

از نسخه ۱٫۱ همه تصاویر فروشگاه **عکس واقعی** هستند و با راه‌اندازی فروشگاه (ابزارها ← دموی فروشگاه دانه) خودکار روی محصولات، گالری‌ها، دسته‌ها و تصویر صفحه اصلی قرار می‌گیرند.

## چه چیزی ساخته شده و چه چیزی عکس آماده است

| تصویر | منبع |
| --- | --- |
| بسته‌های ۶ قهوه و دو پک سه‌تایی | **طراحی برچسب اختصاصی «دانه»** روی عکس یک بسته کرافت خام (موکاپ). برچسب‌ها، رنگ هر خاستگاه، نقطه‌های درجه برشت و متن‌ها برای همین پروژه طراحی شده‌اند. |
| عکس دوم گالری قهوه‌ها، دمی‌افزارها، تصویر صفحه اصلی و دسته‌ها | عکس واقعی از **Pexels**، برش مربع و تنظیم رنگ یکدست |

هیچ عکسی از سایت فروشگاه دیگری برداشته نشده و در عکس‌ها لوگوی برند دیگری دیده نمی‌شود.

## جایگزینی با عکس خودتان

بهترین عکس برای یک فروشگاه واقعی، عکس محصول خود فروشگاه است. با گوشی، کنار پنجره و روی یک پس‌زمینه ساده، از همه بسته‌ها با یک زاویه عکس بگیرید.

1. عکس‌ها را **مربع** و حدود ۱۲۰۰×۱۲۰۰ پیکسل کنید (عکس صفحه اصلی افقی، نسبت ۷ به ۵).
2. هر فایل را با شناسه محصول نام‌گذاری کنید:

| محصول | نام فایل |
| --- | --- |
| تصویر بزرگ صفحه اصلی | `hero.jpg` |
| اتیوپی یرگاچفه | `dn-eth-yrg.jpg` |
| کلمبیا هویلا | `dn-col-hui.jpg` |
| برزیل سرادو | `dn-bra-cer.jpg` |
| ترکیب اسپرسو دانه | `dn-esp-bld.jpg` |
| کنیا AA | `dn-ken-aa.jpg` |

برای عکس دوم و سوم گالری، `-2` و `-3` به آخر نام اضافه کنید، مثل `dn-eth-yrg-2.jpg`.

3. پیشخوان ← **ابزارها ← تصاویر محصولات دانه** ← همه را با هم انتخاب و «بارگذاری و جایگزینی» را بزنید.

عکسی که خودتان بارگذاری کنید با اجرای دوباره راه‌اندازی فروشگاه عوض نمی‌شود.

اگر عکس آماده از سایت دیگری می‌خواهید، فقط از سایت‌هایی مثل Pexels یا Unsplash بردارید که استفاده تجاری را مجاز می‌دانند، نه از سایت فروشگاه‌ها، گوگل ایمیجز یا اینستاگرام.
